docker --version -> Check version of docker.
docker pull <image_name> → Download an image from Docker Hub.
docker images -> List all downloaded images on your system.
docker run <image_name> → Create and start a container from an image.
docker run -it <image_name> → Run container in interactive mode (terminal access).
docker run -d <image_name> → Run container in detached (background) mode.
docker run --name <name> <image_name> → Assign a custom name to the container.
docker run -p host:container <image_name> → Map host port to container port.
docker run -v host:container <image_name> → Mount a volume for file sharing.
